  1. console.firebase.google.com → 새 프로젝트 만들기
  2. 왼쪽 빌드 → Realtime Database → 데이터베이스 만들기 (위치 선택, 테스트 모드)
  3. 규칙 탭에 아래를 붙여넣고 게시
  4. 데이터 탭 위의 URL(https://…-default-rtdb.firebaseio.com)을 복사해 위에 붙여넣기
{ "rules": { "pickleOffice": { ".read": true, ".write": true } } }
테스트 모드 기본 규칙은 30일 뒤 만료돼요. 위 규칙으로 바꿔두면 계속 씁니다. 주소를 비우면 서버 없이 로컬 저장으로만 돌아가고, 서버가 끊겨도 화면과 입력은 그대로 동작합니다.
